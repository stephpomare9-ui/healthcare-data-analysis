# Healthcare Patient Analytics 

## Project Overview 
This project analyzes 50,000+ healthcare records to identify trends in patient demographics, hospital stays, admissions, and billing using Excel, SQL, and Python.

---

## Tools Used 
- Excel (Data cleaning)
- MySQL (SQL analysis)
- Python (pandas, matplotlib)
- Streamlit (interactive dashboard)

---

## Dataset 
The dataset contains:
- 50,000+ patient records 
- demographics 
- medical conditions 
- billing data 
- admission and discharge dates

---

## Key Analyses 
- Most common medical conditions 
- Average billing by condition
- Lenght of stay analysis 
- Obesity patients by age group 
- Long-stay patient age distribution

---

## Visualizations
Created visualizations in Python including:
- Most common medical conditions 
- Length of stay by condition (boxplot)
- Admissions over time (line chart)
- Age distribution of long-stay patients (pie chart)

---

## Key Findings
- Arthritis was the most common condition
- Patients aged 45-60 the highest proportion of long stay hospital stays 
- Emergency admissions represented a significant share of total admissions
